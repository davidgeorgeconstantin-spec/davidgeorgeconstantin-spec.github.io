How I build

What employers ask for, built in

Junior web and WordPress job ads keep asking for the same basics. Here is how this site and the demos cover them.

  • Responsive. Mobile-first CSS, tested on phone, tablet and desktop widths.
  • Accessible. Skip link, keyboard navigation, focus styles, alt text, labelled forms, reduced-motion support.
  • Semantic HTML. Proper landmarks and heading order; HTML checked with a validator.
  • Fast. No frameworks, no web fonts, lazy-loaded images, cached assets; checked with Lighthouse.
  • SEO basics. Unique titles and descriptions, Open Graph tags, sitemap.xml and robots.txt.
  • WordPress & PHP. A custom theme and a PHP form with server-side validation and escaping.
  • Forms. Client and server validation, clear error messages, spam protection.
  • Cross-browser. Standard CSS and plain JavaScript, no browser-specific hacks, made for all modern browsers.
  • Deploy-ready. Plain static files with a vercel.json config and no build step.
