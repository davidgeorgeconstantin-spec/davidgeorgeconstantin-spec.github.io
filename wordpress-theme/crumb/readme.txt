=== Crumb ===
Contributors: David Constantin
Requires at least: 6.0
Tested up to: 6.6
Requires PHP: 7.4
License: GPLv2 or later

A minimal classic WordPress theme made from scratch as a portfolio demo for a
fictional bakery ("Crumb & Co."). It is a learning/demo project, not a commercial theme.

== Features ==
* Classic PHP templates: header.php, footer.php, index.php, page.php, single.php
* Primary + footer menus, custom logo, featured images, footer widget area
* Skip link, keyboard-friendly mobile menu with aria-expanded, visible focus styles
* All output escaped (esc_html, esc_attr, esc_url, wp_kses_post)
* No jQuery, no page builder; one small stylesheet

== Install ==
Appearance > Themes > Add New > Upload Theme > choose crumb.zip > Activate.
