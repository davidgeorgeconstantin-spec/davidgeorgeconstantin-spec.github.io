How this page maps to the theme

The live theme is PHP, so this static page shows the same markup and stylesheet. In WordPress the header comes from header.php, the post cards from the loop in index.php, and the footer widgets from footer.php.

<?php while ( have_posts() ) : the_post(); ?>
  <article <?php post_class( 'entry' ); ?>>
    <h2 class="entry-title"><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
    <?php the_excerpt(); ?>
  </article>
<?php endwhile; ?>

Download crumb.zip and upload it under Appearance → Themes → Add New.
