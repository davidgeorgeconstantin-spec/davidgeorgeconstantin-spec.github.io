FixFlow Plumbing — local service website

Lead-focused site for a local plumber: click-to-call, service areas, FAQ accordion and an instant price estimator.

Open live demo
Business
FixFlow Plumbing, a fictional local plumber
Type
Local service
My role
Design & code
Tech
HTML, CSS, JavaScript

The problem

People looking for a plumber are often in a hurry. They want to call quickly and get an idea of the price first.

The solution

A lead-focused page with a click-to-call button that is always visible on mobile and a live price estimator that updates as the visitor chooses options.

Key features

  • Instant price estimator (job type, urgency, hours) that updates live
  • Click-to-call button and sticky mobile call bar
  • Service areas list
  • FAQ built with native <details> elements, keyboard accessible by default

Quality checks

  • Responsive from 320px phones to wide desktop screens
  • Keyboard navigation and visible focus states
  • Labelled form fields and readable colour contrast
  • No frameworks: plain HTML, CSS and JavaScript
