Trattoria Lumea — restaurant website

One-page restaurant site: menu with JavaScript tabs rendered from data, opening hours and a table-booking form that blocks past dates.

Open live demo
Business
Trattoria Lumea, a fictional family restaurant
Type
Restaurant
My role
Design & code
Tech
HTML, CSS Grid, JavaScript

The problem

A small restaurant needs guests to find the menu, the opening hours and a way to book a table in a few seconds, usually on a phone.

The solution

A single, fast page with the most important actions at the top. The menu is stored as JavaScript data and rendered into tabs, so updating a dish means editing one line.

Key features

  • Menu tabs (starters, pasta, desserts) generated from a data array
  • Opening hours and contact block
  • Table-booking form that blocks past dates and shows a confirmation message
  • Mobile-first layout with CSS Grid

Quality checks

  • Responsive from 320px phones to wide desktop screens
  • Keyboard navigation and visible focus states
  • Labelled form fields and readable colour contrast
  • No frameworks: plain HTML, CSS and JavaScript
